# Rig: no weight. The script sets a weak spring first, so the rim rests where it's left and
# any sideways force turns it. Keep hands off the rim. About 1 minute.
#   P1: the patent's effect-block layout (constant force, infinite, gain 80, 1 loop)
#   P2: rumble-shaped, 25% in both bytes

00 00 0b 04
00 00 0b 48
